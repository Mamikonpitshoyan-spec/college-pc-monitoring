Установка агента на юзерские компьютеры — БЕЗ флешки и без bat-файлов:

1. На админском компе открой дашборд Monitoring Admin (должен быть запущен).
2. На юзерском компе открой в браузере:  http://<адрес-админского-компа>:8000/download
   (адрес виден в модалке «＋ Добавить компьютер» — кнопка «Скопировать ссылку»).
3. Скачай MonitoringAgent-Setup.zip, распакуй, запусти MonitoringAgentApp.exe.
4. Windows спросит права администратора — «Да» (один раз, для температуры и службы).
5. В приложении введи код сопряжения из «＋ Добавить компьютер» → «Установить и подключить».
6. Администратор жмёт «Принять» — компьютер появляется в системе.

Старые bat-установщики больше не нужны: установка встроена в приложение.
